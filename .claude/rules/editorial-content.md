# Editorial content rules

- No grading system, ever: no badges, star ratings, color-coded scores, or
  Strong/Moderate/Weak labels on any candidate-facing content.
- Every claim traces to a cited URL with publication + date. A citation by title alone is
  not acceptable; every URL found for a candidate goes into that candidate's sources array.
- Verbatim quotes only. Never paraphrase a statement and present it as a direct quote; use
  `[sic]` only for obvious transcription errors in the original.
- Zero scripture quotes and no "biblical/unbiblical" labels anywhere in candidate-facing
  text — the Judeo-Christian lens shapes what gets researched, never the voice on the page
  (`CODEX_HANDOFF.md:96-135`).
- Symmetry test on every narrative sentence: would it read identically, with the same word
  choices, about an opposite-party candidate given the same evidence? Avoid partisan
  shorthand (MAGA/woke/RINO/fascist/socialist-as-slur) and charged verbs (claimed/alleged/
  ranted/slammed) — use neutral verbs instead (`CODEX_HANDOFF.md:143-181`).
- Never call a statement a "lie" — write "this contradicts [fact] reported by [source]"
  instead (`CODEX_HANDOFF.md:923-965`).
- A KPDC (Kansas Political Disclosure Commission) account alone is NOT proof of candidacy —
  a recurring past error; verify against official filings or FEC status
  (`AGENTS.md:362-373`).
- "In Their Own Words" sections are banned — a prior social-narrative pipeline built this
  out fully in `CODEX_HANDOFF.md`, then it was explicitly reversed in `AGENTS.md:445`. Don't
  resurrect the section even if you find the old spec.
- The fixed 14-issue matrix applies to every candidate, no exceptions — don't drop issues a
  candidate hasn't addressed; mark them unanswered instead (`AGENTS.md:448-467`).
